# STM32 HAL C++封装库

## 📖 项目介绍  
这是本人学习了 C++ 以及 GitHub 提交后以研究与练习为目的所写的项目，对 STM32 的一些常用功能进行了封装以方便开发。

---

## 🛠 技术规格  
| 类别        | 详细信息                 |
|-------------|--------------------------|
| **语言**    | 最低C++11，建议C++17                    |
| **依赖库**  | STM32Cube HAL 库         |
| **硬件平台**| 推荐STM32F4 系列及更强系列   |

---

## ⚠️ 使用要求  
本项目完全开源，使用时只需要说明这个项目的来源即可。
